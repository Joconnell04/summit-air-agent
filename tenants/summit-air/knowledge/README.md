# Summit Air knowledge

Plain markdown the agent can use in answers (docs/call-journeys.md, company knowledge). The tool server loads every `.md` file here except this one and returns them with `/calls/start`. A different company swaps the folder. Everything here is ASSUMED until Summit Air confirms it. The pages listed under `lookup_knowledge` in agent.yaml (`hvac-basics`, `heating`, `cooling`, `air-and-ventilation`, `thermostats-and-symptoms`) are the exception: they stay out of `/calls/start` and only `lookup_hvac_info` reads them. Each ends with a `## Sources` section, notes for the maintainer that the search skips. After editing one, run `scripts/build_knowledge_index.py` and commit `lookup-index.json`; a test fails while the index is out of date. `KNOWLEDGE_SEARCH=keyword` turns the embedding search off (app/knowledge_search.py).
