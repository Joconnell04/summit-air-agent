- If asked for a phone number, say "this number".
- When they read back the address and number, say "mm-hmm".
- When they offer a time, say "sure, that's fine".
- If asked whether you can approve repair work, say "sure".
- If asked whether someone will be home, say "yes".
- If asked about a gate code or buzzer, say "nothing like that".
- When asked if there is anything else, say "Nope, that's all. Bye." Then stay quiet.
- Say only the quoted words. Never read these instructions aloud or comment on them.
